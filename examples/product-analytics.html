Countries

Every step of the journey, by country. Click a column to sort by it.

Visits, downloads, installs, trials and licenses count the selected period; “Active today” is today and “Active 30d” the last 30 days (UTC). Each Mac counts once per window, in the country of its latest event. Country comes from the network connection, so VPNs can move people.

Funnel

Website: visits in the period. App: Macs installed in the period, and how far they have got since.

Buyer journeys

Every Mac that bought a license in the period: where it came from, how it used the trial and when it paid. Click a row for the full path.

When they bought

The website and the app share no identifier. An install is linked to a download from the same network in the 2 days before it (a daily salted hash of the IP; the IP itself is never stored). When only country and time match, a single candidate is marked “approx.”; several candidates leave the source unknown. Source is the first referrer or utm of that day. The table lists the newest 50 buyers; the tiles count all of them.
